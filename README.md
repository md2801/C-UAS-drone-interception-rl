# CUAS Reinforcement Learning Project

Counter-UAS system using deep reinforcement learning for drone detection, tracking, and interception.

## Project Structure
- `src/detection/`: Drone detection modules
- `src/tracking/`: RL-based tracking algorithms
- `src/interception/`: Interception strategies
- `notebooks/`: Jupyter notebooks for experiments
- `configs/`: Configuration files
- `models/`: Trained model weights
